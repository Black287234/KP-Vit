**Тема:** «Проектирование и разработка модуля бронирования оборудования».
**Проект:** EquipmentBooking (ASP.NET Core Razor Pages, .NET 10). **Репозиторий:** https://github.com/Black287234/KP-Vit

Архив для сдачи: `git archive -o stageN.zip HEAD`.

## Этап 1. Поле ответа

**Тема и назначение.** Модуль бронирования оборудования (проекторы, ноутбуки, камеры) для сотрудников колледжа и ответственного за оборудование.

**Обязательные функции:**
- каталог;
- выбор периода;
- проверка доступности;
- создание и отмена брони;
- текущие и завершённые брони;
- справочник сотрудников.

**Сущности:**
- **Equipment:** инвентарный номер, название, категория, описание, состояние.
- **Employee:** ФИО, подразделение, почта.
- **Booking:** оборудование, сотрудник, начало, окончание, цель, статус, данные отмены.
- **BookingHistory:** журнал операций по брони.
- **Связи:** оборудование 1—N броней, сотрудник 1—N броней.

**Главное правило.** Нельзя забронировать оборудование на период, пересекающийся с другой активной бронью этого же оборудования. Условие пересечения: `новоеНачало < существующийКонец && новыйКонец > существующееНачало`.

**Что работает.** Проект Razor Pages на .NET 10, модель Equipment, каталог на странице и по GET /api/equipment (данные в памяти).

**Ближайший шаг.** SQLite + EF Core.

## 20 вопросов и ответы

1. **Главное правило?** Нельзя бронировать оборудование на период, пересекающийся с другой активной бронью этого оборудования.
2. **Как проверяется пересечение?** По условию `новоеНачало < конец && новыйКонец > начало`. Оно записано в BookingRules.Overlaps и в запросе BookingService.Create.
3. **Почему 12:00–14:00 после 10:00–12:00 допустимо?** Момент окончания в бронь не входит, и 12:00 < 12:00 — ложь.
4. **Мешают ли отменённые брони?** Нет, в проверке участвуют только активные.
5. **Почему брони не удаляются?** Чтобы оставалась история: кто и когда пользовался оборудованием. Вместо удаления есть отмена с причиной.
6. **Как бронь становится завершённой?** Метод CompleteExpired перед выводом списков переводит активные брони с прошедшим окончанием в статус «Завершено» и пишет запись в журнал.
7. **Что такое TimeProvider и зачем он?** Это источник текущего времени. В тестах его заменяют «остановленными часами», чтобы проверить «прошлое» и автоматическое завершение.
8. **Что будет, если два человека одновременно бронируют одно и то же?** Проверка и сохранение идут внутри `lock`, поэтому второй запрос увидит первую бронь и получит отказ.
9. **Почему Razor Pages, а не MVC?** Приложение состоит из самостоятельных страниц с формами. В Razor Pages код страницы лежит рядом с разметкой, и так проще.
10. **Что такое PageModel?** Класс страницы: методы OnGet и OnPost принимают запрос, вызывают сервис и готовят данные для разметки.
11. **Почему нельзя списать проектор с текущими бронями?** Иначе брони останутся на неисправное оборудование. Сначала их нужно отменить.
12. **Можно ли вернуть списанное оборудование?** Нет: списание — это архив, запись остаётся ради истории.
13. **Как устроена страница «Свободно ли?»** Для каждой единицы каталога проверяются состояние и пересекающиеся активные брони. Результат — свободные единицы и занятые с причиной.
14. **Как работает фильтр по дате?** Отбираются брони, которые пересекаются с отрезком от начала этого дня до начала следующего.
15. **Что такое миграция?** Описание структуры базы в коде. `Database.Migrate()` создаёт таблицы при запуске.
16. **Зачем индекс (EquipmentId, StartAt, EndAt)?** Он ускоряет поиск пересечений по конкретному оборудованию.
17. **Как устроены тесты?** xUnit и SQLite в памяти: новая база и «часы» на 12.11.2026 09:00 для каждого теста. 52 проверки покрывают правила, сервисы, поиск и каталог.
18. **Как проверено сохранение?** В тесте данные читаются новым DbContext. Вручную: приложение перезапускали, и добавленное оборудование с бронями оставалось на месте.
19. **Что будет при неизвестном Id?** Откроется страница «Запись не найдена (404)», а API вернёт 404 с текстом.
20. **Что можно улучшить?** Добавить роли, напоминания на почту, повторяющиеся брони, учёт выдачи и возврата и фоновое автоматическое завершение.
